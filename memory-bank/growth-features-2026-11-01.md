## Implementation and boundaries
- One ratings-notification entry in mobile header or wide sidebar, never two mounted dialogs.
- GA4 authenticated_entry replaces misleading signup_completed for new authenticated entries including restored sessions. Legacy server series retains its old event key, relabelled as authenticated entries. Anonymous session totals are not labelled DAU/MAU. Admin-only member aggregates exclude known operator, moderator, QA and demo handles; these are account counts, not verified people.
- Optional awaiting-ratings feed: published public posts, 0–10 stored nonauthor ratings, excluding owner, already-rated and blocked posts. Existing ordinary feed is retained; failures do not silently substitute it.
- Optional A/B: exactly two photos and a binary category, existing vote encoding yes=A/no=B. No aggregate results before vote except the post author. Comparison preference is excluded from overall approval rankings.
- Public sharing preview requires explicit per-post opt-in on public posts. No result values in metadata. The server rechecks current post access on every request; no extra media copy or CDN cache is created. Existing permanent deletion is unchanged. External platforms may retain their own copies, disclosed before opt-in.
- Preview photos are at most 512 KiB, limited to 50 image fetches/day across the project. Larger media and video use a brand icon, retaining text metadata when permitted. No user/IP tracking is added.
- Push subscriptions require explicit device permission, verified member identity and a known push-service host. Notification claims require a saved vote and are idempotent per post; existing voted posts are baselined. Notifications contain only generic feedback availability, not results or post content. Failed delivery must not fail the original vote. Stale subscriptions are purged after 90 days; sign-out attempts to unsubscribe, and always proceeds with sign-out even if that fails.
- YouTube and GA4 API reads are admin-only; aggregates use a 24h DB cache. YouTube comments are manually loaded, public-only, limited to 10, not persisted or automatically answered. GA4 returns event-name aggregates, never person-level data. No paid API/service transition.
