## 실행 원칙

- 이 목록은 전체 테스트를 요구하지 않는다. 각 조건은 한 번의 관련 실증으로만 확인한다.
- PRE-02·03·06은 데스크톱 축소 화면으로 대체하지 않는다.
- PRE-05의 사실 정보가 확정되기 전에는 기존 정책 초안을 정식 고지로 표시하지 않는다.
- 새 운영 증상은 해당 PRE 행의 증거를 갱신한 뒤에만 수정 과제로 분리한다.
