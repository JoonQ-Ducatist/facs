## PRE-05 정식 정책 문구 준비

현재 `LegalPolicyDialog.jsx`의 한·영 문구는 Closed Beta 안내 초안이며 정식 고지가 아니다. 도메인은 이미 누구나 접근 가능하므로 이를 장래 출시 전 준비가 아닌 현행 공개 운영의 우선 보완 항목으로 다룬다. 코드에는 Supabase 인증·미디어 저장, 게시물·평가·댓글·신고·차단·권리 동의, 세션·분석 이벤트 처리가 확인된다. 이 목록은 실제 운영 설정과 법적 고지 범위를 확정했다는 뜻이 아니다.

| 결정 항목 | 현재 확인 상태 | 정식 문구 전에 필요한 정보 |
| --- | --- | --- |
| 운영 주체·문의 | 승인된 운영 주체 `Tweety and Company`, 공식 연락처 `teamfactsmack@gmail.com`을 한·영 정책 안내에 반영 | 정식 정책 법률 검토 시 책임자·문의 범위 확인 |
| 처리 항목·외부 서비스 | 아래 코드 기반 목록과 운영 Supabase 리전·인증 제공자·SMTP 설정, Vercel 플랜·배포·사용량 확인 | 실제 수집 항목·목적, 외부 서비스 계약·보존·국외 이전 사실 확인 |
| 보존·삭제 | 2026-10-09 사용자 결정으로 작성자 삭제 게시물·댓글의 실제 파기 전환을 시작했다. 운영 DB 마이그레이션과 Storage 삭제 실증 전까지 운영의 기존 소프트 삭제 동작은 유지된다. 계정 탈퇴와 분석 이벤트 만료는 별도 과제 | DB·Storage·연결 기록의 실제 삭제를 확인하고 백업 보존 기준과 정식 정책을 일치시킨다. 계정 탈퇴는 `REL-05` |
| 미성년자·콘텐츠 | 신고 기준 초안 존재 | 가입 가능 연령과 검토·이의제기·콘텐츠 조치 기준 확정 |
| 검토·게시 | 정식 문구 법률 검토 미완료 | 확정된 한국어 원문 검토 후 영어 문구 대조, 발효일·변경 고지 방식 확정 |

위 사실을 받기 전에는 임의의 기간·사업자·위탁 사실을 만들어 넣거나 초안을 정식 정책으로 표시하지 않는다.

운영 DB 마이그레이션과 실제 삭제 검증 전에는 운영의 소프트 삭제를 영구 파기로 설명하지 않는다. PRE-05는 작성자 삭제의 DB·Storage 파기 확인과 실제 접수·보존 방식의 고지를 요구한다. 계정 탈퇴는 `REL-05`로 유지한다.

### REL-02 최소 운영 관측

- 관리자 전용 `get_mvp_operational_metrics(24)`는 최근 24시간의 신규 회원·게시물·평가·댓글·신고 처리와 익명 퍼널 합계, 현재 미처리 신고 수·가장 오래된 접수 시각만 반환한다.
- 개별 회원·게시물·신고·세션 원문은 운영 지표 응답에 포함하지 않는다. 조회 범위는 1~168시간으로 제한한다.
- 브라우저 오류는 DB 숫자로 추정하지 않고 Vercel Runtime Logs의 실제 오류 시각·경로와 사용자 문의를 대조한다.
- 자동 경보 서비스나 임의 임계치는 추가하지 않는다. 공개 초기의 확인 주기와 주의 기준을 운영자가 확정한 뒤 필요한 알림만 별도 승인한다.
- 2026-10-05 사용자 승인 후 운영 Supabase SQL Editor로 함수를 적용했고, 함수 존재와 `anon=false`·`authenticated=true` 실행 권한을 확인했다. 함수 내부의 `admin` 역할 검사와 1~168시간 제한은 저장소 계약 테스트 3개로 확인했다.

### Vercel 플랜 전환 게이트

- 현재 공개 MVP에서는 결제 요청·처리, 유료 기능 판매, 광고가 비활성이다. 운영 목적과 유료 직원·외주 참여 여부를 확인해 현재 Hobby 적격을 별도 판정한다.

- 플랜 전환, 결제수단 등록, 지출 한도 설정은 별도 사용자 승인 없이 실행하지 않는다.
- 근거: https://vercel.com/docs/limits/fair-use-guidelines (2026-09-14 갱신)

### Supabase Free 운영 게이트

- 공개 확대 전 운영 대시보드에서 DB, Storage, egress 사용량을 한 번 기록한다.
- Free에는 자동 백업과 PITR가 없으므로 운영 데이터의 수동 복구본 생성·보관 절차를 정한다.
- 1주 비활성 일시중지와 짧은 로그 보존으로 장애 원인을 놓칠 수 있으므로 문의에는 발생 시각을 필수로 받는다.
- DB 500MB, 파일 1GB, egress 5GB 한도에 근접하거나 무중단·자동 복구가 필요해지면 `OPS-01` 묶음 작업에서 Pro 전환을 승인한다.
- 플랜 전환, 결제수단 등록, 지출 한도 변경은 별도 사용자 승인 없이 실행하지 않는다.
- 근거: https://supabase.com/pricing, https://supabase.com/docs/guides/platform/backups
