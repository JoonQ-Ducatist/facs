# 로그인 서비스 안내를 선택형 팝업으로 전환

사용자 요청: 로그인 하단의 고정 안내 영역을 없애고 약관·개인정보 링크처럼 서비스 안내(About Us)를 선택할 때만 표시한다.

- AuthEntryView 고정 설명 section을 제거하고 기존 링크 행에 서비스 안내/ About Us를 추가했다.
- 기존 LegalPolicyDialog에 about 유형을 추가해 이전 설명 2문단을 한·영으로 제공한다. 안내에 약관 시행일은 표시하지 않는다.
- `?policy=about` 직접 접근도 기존 정책 링크 방식으로 지원한다. 안내를 열 때 기존 policyOpen 상태를 사용하므로 PWA 안내와 겹치지 않는다.
- 기존 약관·개인정보·신고 링크, 로그인 인증·저장, SEO 메타·정적 HTML, GA4, PWA 설치/숨김 규칙은 수정하지 않았다. 정적 소개는 JavaScript 초기화 전 HTML이며 로그인 렌더 이후 고정 영역은 없다.
- 선택 계약 테스트 2건 통과: 고정 안내 제거·about 진입과 한·영 설명 유지, 정적 검색 메타/언어별 HTML 계약. 전체 테스트·빌드·Preview·DB 변경은 실행하지 않았다.
- 로컬 Chrome `http://127.0.0.1:4173/ko/?authPreview=1`에서 고정 안내 없이 서비스 안내 링크만 표시됨을 확인했다. 링크를 키보드로 활성화해 한국어 안내 팝업·기존 2문단 표시를 확인하고 닫기 버튼으로 닫은 뒤 안내 영역이 없는 로그인 화면으로 복귀했다. 이 미리보기 확인은 실제 인증 성공을 의미하지 않는다.
- 사용자가 수정 내용을 승인했다. 작업 브랜치 `work/facs-about-dialog`를 커밋·원격 보관하고 main 병합 후 Git 연동 운영 배포 1회로 반영한다. 배포 결과는 복구 태그 주석에 기록해 추가 문서 배포를 피한다.
