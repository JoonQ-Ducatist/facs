# FACt.Smack 글로벌 운영·사실성·결제 규칙

> 상태: 2026-09-04 제품 규칙 확정. 구현은 각 백로그의 안전·법무·보안 조건을 충족한 뒤 진행한다.

## 1. 관계와 평가자 익명성

- 회원은 공개 프로필의 `@핸들`을 눌러 프로필을 확인하고 승인 없는 단방향 팔로우를 할 수 있다.
- 일반 사용자와 업로더에게는 YES/NO 또는 나이 평가를 남긴 **개별 평가자의 핸들·프로필·연결 관계를 절대 공개하지 않는다**.
- 일반 화면에는 집계값·유효 표본만 제공한다. 평가자 식별·원문 로그는 권한 있는 관리자만 부정행위·분쟁·법적 요청 목적에서 최소 범위로 열람하며, 모든 열람은 사유·시각·관리자 ID를 감사 로그에 남긴다.

## 2. 위치 기반 사실 정보

- `어디에서 찍은 사진이에요?`는 선택적 컨텍스트 정보다. EXIF·기기 위치·사용자 입력 중 동의받은 출처만 사용하며 자동 공개가 기본값이 아니다.
- 공개 전 업로더가 장소 표시를 명시적으로 승인한다. 기본 공개 단위는 정확한 주소가 아닌 `동네/도시/공개 장소명`이며, 주거지·학교·의료기관·정확한 좌표·민감 장소는 자동 차단 또는 사람 검토 대상이다.
- 출처와 확실성 상태(`사용자 입력`, `사진 메타데이터 확인`, `확인 불가`)를 기록한다. AI 추정만으로 장소를 사실처럼 표시하지 않는다.
- 피드 카드에는 사진을 가리지 않도록 장소명을 상시 오버레이하지 않는다. 게시물 상세/댓글 더보기 패널의 작성자·설명 아래에 작고 선택적인 `촬영 장소` 행으로 노출한다.

## 3. 모바일 햅틱

- 모바일 BINARY 평가에서 YES는 짧고 잔잔한 단일 햅틱, NO는 더 분명한 이중 햅틱을 시도한다.
- 브라우저·OS·사용자 설정이 허용할 때만 동작하며 비지원 환경도 동일한 기능을 제공한다. 햅틱은 즉시 피드백일 뿐 결과·노출 순서 조작 수단이 아니다.

## 4. 언어와 지역

- 기본 지원 언어는 한국어(`ko`), 영어(`en`), 중국어(`zh`)다. 일본어(`ja`)는 일본 사용자 추이·콘텐츠 검토 역량·결제 지원을 검토한 뒤 추가한다.
- 운영 언어는 Vercel 국가 신호(US, GB, CA, AU, NZ, IE, SG, ZA, IN, PH는 `en`, KR은 `ko`)를 우선 제안하고, 다른 국가는 지원되는 브라우저 언어를 fallback으로 사용한다. 사용자의 URL 언어 선택이 우선하며, IP 원문은 FACS에 저장·노출하지 않는다.
- 한국 테스트 환경과 한국 접속 기본 화면은 한국어만 표시한다. 영어권에는 메뉴·상태·카테고리·카피를 영어로, 중국어권에는 중국어로 제공한다. 사용자 콘텐츠 원문은 유지하고 번역 표시는 별도 기능이다.
- **모든 신규 UI는 한국어와 영어를 동시에 완료 조건으로 한다.** 메뉴·버튼·오류·빈 상태·단위·수량·날짜·접근성 라벨·모달·관리 화면을 포함한 서비스 제공 기본 문구는 두 언어의 단일 메시지 키로 관리한다. 한 언어의 문구만 하드코딩하거나, 화면 렌더 뒤 DOM 치환으로 번역 품질을 보완하는 방식을 출시 구현으로 사용하지 않는다.
- 영어 문자열은 한국어보다 길 수 있으므로 각 화면은 긴 단어·복수형·통화 단위를 기준으로 줄바꿈·말줄임·최소 폭을 검증한다. 아이콘 폰트·숫자·통화·단위는 로케일 본문 폰트의 영향을 받지 않도록 분리한다.

## 5. 우선 노출과 가격

- Boost 결제 게시물은 공개 범위·차단 규칙을 통과한 독립 사용자에게 우선·다빈도 노출된다. 동일 사용자 중복 노출, 결과 조작, 우호 평가자 배정은 금지한다.
- 최초 100명 목표 Boost는 한국 원화 **₩1,000**, 영어권 기준 **US$1.00**으로 시작한다. 다른 지원 국가는 세금·결제 수수료·통화 규칙을 투명하게 반영한 동등 가치의 현지 통화 가격을 적용한다.
- Bitcoin 결제는 결제 서비스·규제·보안 검토가 완료된 국가에서만 제공한다. 서비스가 개인 지갑 주소나 비밀키를 저장·노출하지 않으며, 결제 제공자의 견적·환율 잠금·온체인 확인·미결제 만료·환불·감사 로그를 통해 처리한다.

## 6. 5:5 규칙

- YES/NO 5:5 비율 규칙은 일반 Feed·Boost·Ranking에 적용하지 않는다. 별도 **Tournament** 실험에서만 사용하며 일반 평가 데이터와 집계를 분리한다.
