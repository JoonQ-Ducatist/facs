# 공개 MVP 정식 정책 결정표

작성일: 2026-10-04

이 문서는 현재 운영 사실과 정식 정책에 필요한 결정을 분리한다. 법률 검토본이 아니며,
확인하지 않은 보존기간·국외 이전·법적 근거를 만들어 넣지 않는다.

## 1. 확인된 운영 사실

| 영역 | 현재 사실 |
| --- | --- |
| 운영자·문의 | `tweety and company`, `joonkyou.park@gmail.com` |
| 공개 범위 | `factsmack.com`은 누구나 접근할 수 있는 공개 MVP |
| 인증 | 이메일 인증과 Google OAuth 사용, Kakao 비활성 |
| 계정·프로필 | 인증 계정 정보, 공개 아이디, 프로필 사진 경로, 역할 처리 |
| 콘텐츠 | 사진·짧은 동영상, 질문, 카테고리, 공개 범위, 게시 시각 처리 |
| 상호작용 | 평가, 댓글, 팔로우, 차단, 스크랩, 신고·검토 기록 처리 |
| 권리 확인 | 업로드 권리 보유 확인의 동의 버전과 시각 처리 |
| 분석·브라우저 저장 | 퍼널 이벤트, 익명 세션 식별자, 인증 세션, 언어·평가 완료·일부 UI 복구 상태 저장 |
| 인프라 | Supabase Free 서울 리전, Vercel Hobby, Gmail SMTP |
| 삭제 | 게시물·댓글 삭제는 현재 공개 화면에서 숨기는 소프트 삭제. 계정 탈퇴와 영구 파기는 공개 MVP 이후 `REL-05` |

## 2. 공개 MVP 전에 확정할 결정

| 순서 | 결정 | 권장 방향 | 결정 전 정책에 쓰지 않을 내용 |
| ---: | --- | --- | --- |
| 1 | 가입 가능 연령 | **승인:** 법정대리인 동의 흐름이 없으므로 공개 MVP는 만 14세 이상으로 제한 | 아동 계정을 받을 수 있다는 표현 |
| 2 | 삭제·보존 운영 | **승인:** 영구 삭제 기능 전에는 소프트 삭제 사실과 이메일 요청 절차를 그대로 고지. 영구 삭제·탈퇴는 공개 MVP 이후 제공 | 즉시 또는 자동 영구 삭제된다는 표현 |
| 3 | 신고·분쟁 기록 보존 | 신고 적용·반려와 이의·문의 처리에 필요한 실제 보존 기준을 운영자가 확정 | 확인되지 않은 임의의 연·월 단위 기간 |
| 4 | 정보주체 요청 | **승인:** 열람·정정·삭제·처리정지·문의는 공식 이메일 `joonkyou.park@gmail.com`으로 접수. 본인 확인·회신 절차는 정식 문구 작성 시 구체화 | 앱 안에서 자동 처리된다는 표현 |
| 5 | 외부 처리·국외 이전 | Supabase·Vercel·Google의 계약상 처리 주체, 국가, 항목, 목적, 시기·방법, 보유기간을 법률 검토로 확인 | 서울 DB 리전만으로 국외 이전이 없다고 단정 |
| 6 | 정책 시행 | 한국어 원문, 영어 대조본, 시행일, 중요한 변경의 사전 고지 방식을 확정 | 현재 `Closed Beta` 문구 유지 |

## 3. 정식 문서 구조

### 이용약관

1. 목적과 서비스 성격
2. 가입 자격과 계정 책임
3. 업로드 권리와 금지 콘텐츠
4. 주관적 평가 결과의 한계
5. 신고·차단·콘텐츠 조치
6. 서비스 변경·중단과 책임 범위
7. 문의, 시행일, 변경 고지

### 개인정보 처리방침

1. 개인정보 처리 목적
2. 처리 항목과 수집 방법
3. 처리·보유 기간
4. 제3자 제공 여부
5. 처리 위탁과 국외 이전
6. 파기 절차·방법과 별도 보존
7. 정보주체의 권리와 행사 방법
8. 아동의 개인정보
9. 브라우저 저장·쿠키 및 분석
10. 안전성 확보조치, 보호책임자·고충처리, 시행일

### 콘텐츠·신고 기준

1. 허용하지 않는 콘텐츠
2. 신고 접수와 중복 방지
3. 신고 적용·반려 기준
4. 콘텐츠 숨김과 계정 조치
5. 긴급 위험과 외부 기관 신고
6. 문의와 향후 이의제기 절차
